**推荐：RustDesk 作为主要远程桌面，x11vnc 作为备用连接方案**

## 1. RustDesk

### 1.1 安装

从[官方网站](https://rustdesk.com/)和[GitHub](https://github.com/rustdesk/rustdesk/releases)上下载安装包

> Ubuntu 20.04 默认软件源缺少 gstreamer1.0-pipewire，因此安装 RustDesk 1.5.0.deb 时会出现问题，建议使用 AppImage 便携版

赋予执行权限：

```bash
chmod +x ~/lwb/rustdesk-1.5.0-x86_64.AppImage
```

如果缺少 AppImage 运行依赖：

```bash
sudo apt install libfuse2
```

在 Ubuntu 图形终端启动：

```bash
./rustdesk-1.5.0-x86_64.AppImage
```

如果通过 SSH 启动，需要指定 X11 显示器：

```bash
DISPLAY=:0 ./rustdesk-1.5.0-x86_64.AppImage
```

### 1.2 开启局域网 IP 直连

RustDesk 默认通过 ID 服务器建立连接，也支持不依赖公共服务器的局域网直连模式

在服务端 Settings → Security 中开启 Enable direct IP access。保持默认端口 21118。并配置永久访问密码

客户端输入对应`IP`，如果使用非默认端口，也可以尝试 `IP:端口`

### 1.3 RustDesk 开机自启动：systemd 用户服务

使用 systemd 管理 AppImage，获得自动重启能力。创建目录：

```bash
mkdir -p ~/.config/systemd/user
```

创建服务：

```bash
vim ~/.config/systemd/user/rustdesk.service
```

内容如下，注意修改<>中的内容

```ini
[Unit]
Description=RustDesk AppImage Remote Desktop

[Service]
Type=simple
Environment=DISPLAY=:0
Environment=XDG_SESSION_TYPE=x11
ExecStart=<对应的位置>
Restart=always
RestartSec=10

[Install]
WantedBy=default.target
```

启用服务：

```bash
systemctl --user daemon-reload
systemctl --user enable --now rustdesk.service
```

查看状态：

```bash
systemctl --user status rustdesk
```

查看日志：

```bash
journalctl --user -u rustdesk -f
```

## 2. x11vnc + TigerVNC

### 2.1 基本原理

x11vnc 是运行于 Ubuntu 的 VNC 服务端，用于共享现有 X11 物理桌面。

TigerVNC Viewer 是 Windows 客户端，用于显示和操作该桌面。

整个连接过程不需要互联网或第三方服务器。

### 2.2 Ubuntu 安装 x11vnc

```bash
sudo apt update
sudo apt install -y x11vnc
```

创建 VNC 密码：

```bash
x11vnc -storepasswd
```

密码文件默认保存于`~/.vnc/passwd`

手动启动：

```bash
x11vnc -display :0 -auth guess -rfbauth "$HOME/.vnc/passwd" -forever -shared -noxdamage -rfbport 5900
```

### 2.3 Windows 使用 TigerVNC 连接

从[GitHub](https://github.com/TigerVNC/tigervnc/releases)上下载安装包

安装 TigerVNC Viewer，并在地址栏输入`<Ubuntu_IP>::5900`

输入此前设置的 VNC 密码后，即可远程控制远程桌面

### 2.4 配置 systemd 系统服务

创建服务文件：

```bash
sudo vim /etc/systemd/system/x11vnc.service
```

内容如下，注意修改<>中的内容

```ini
[Unit]
Description=x11vnc Remote Desktop Server
After=display-manager.service network.target
Wants=display-manager.service
StartLimitIntervalSec=0

[Service]
Type=simple
User=<用户名>
Group=<用户名>
Environment=HOME=/home/<用户名>
Environment=DISPLAY=:0
ExecStart=/usr/bin/x11vnc -display :0 -auth guess -rfbauth /home/<用户名>/.vnc/passwd -forever -shared -noxdamage -rfbport 5900
Restart=always
RestartSec=5

[Install]
WantedBy=graphical.target
```

关闭此前手动启动的 x11vnc，避免端口冲突：

```bash
pgrep -a x11vnc
pkill -u agx3 -x x11vnc
```

启用服务：

```bash
sudo systemctl daemon-reload
sudo systemctl enable --now x11vnc.service
```

检查状态：

```bash
sudo systemctl status x11vnc
```

检查监听端口：

```bash
ss -lntp | grep 5900
```

查看日志：

```bash
sudo journalctl -u x11vnc -b -n 100 --no-pager
```
